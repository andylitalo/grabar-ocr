# Tōnatsooyts — English (corrected overlay)

**Sparse overlay of line-level patches.** Lists only pages with human-approved English
corrections; each page gives the changed passages as `` `wrong` → `right` `` bullets (or a
fenced full-page block if rewritten wholesale). For any page not listed, the authoritative
English is its `## page_NNNN` section in the pristine machine output
[`book.english.md`](book.english.md).

**Precedence:** `book.english.md` is the base; patches here override it. Every correction
traces to [`ERRATA.md`](ERRATA.md); term normalization follows [`GLOSSARY.md`](GLOSSARY.md).

**Do not edit `book.english.md`** — it is regenerated by `pipeline.promote`. Corrections
live here so they survive re-promotion.
