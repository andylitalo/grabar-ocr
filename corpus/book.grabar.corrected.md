# Tōnatsooyts — Grabar (corrected overlay)

**Sparse overlay.** This file contains `## page_NNNN` sections **only for pages whose Grabar
transcription has human-approved corrections**. For any page **not** present here, the
authoritative Grabar is the corresponding `## page_NNNN` section in the pristine machine
output [`book.grabar.md`](book.grabar.md).

**Format — line-level patches.** Corrections are surgical, so each page lists only the
lines that change, as `` `wrong` → `right` `` bullets (with the `line_id` for traceability).
A consumer applies `book.grabar.md` then, per page below, substitutes the wrong line text
with the right. (Use a full ` ``` ` fenced block for a page only if it is rewritten wholesale.)

**Precedence:** `book.grabar.md` is the base; the patches here override it. Every correction
traces to an entry in [`ERRATA.md`](ERRATA.md).

**Scope:** only fixes where the corpus **misreads what the page prints** (OCR/transcription
error) — including dropping pure-noise lines the `non_character` detector missed. Errors in
the *printed source itself* stay faithfully transcribed and are recorded in
[`TYPOS.md`](TYPOS.md) instead — do not "fix" them here.

**Do not edit `book.grabar.md`** — it is regenerated by `pipeline.promote`. Corrections live
here so they survive re-promotion. (Class-A noise lines are additionally being fixed at the
detector level so a re-promote drops them automatically — see `ERRATA.md` E2.)
